---

## 0. 一句话结论

当前顶栏 `face-sm`（**52px**）仍是「可 poke 的角色立绘」尺度，外发光 + 上浮 hover 也不像会话头像。设置图标是「中心圆 + 八向射线」，观感接近亮度/太阳，不像系统设置。

本期对齐 Messages / Slack / 常见 IM 顶栏习惯：

1. **头像**：约 **28–32px** 正圆裁切，轻描边，无光晕；文案在左、头像贴最右  
2. **设置**：换成 **经典齿轮（cog）** 线框图标，尺寸与 ≡ / 会话按钮一致（16px stroke）

---

## 1. 现状问题

| 元素 | 现状 | 问题 |
|---|---|---|
| 顶栏脸 | `PokeFace size="sm"` → `.face-sm` **52×52** | 高于顶栏行高（~44），像迷你角色不是头像 |
| 脸装饰 | `.face::before` 径向光晕；hover `translateY(-2px)` | IM 头像通常静止圆片，无光晕无跳 |
| 设置图标 | 圆 + 八射线 | 不像齿轮；易被认成主题/亮度 |
| 布局 | `⚙ · 名/情绪 · 脸`（v2 已右置） | 布局保留，只改脸尺度与图标形 |

对标习惯（不必 1:1 抄尺寸）：

- **macOS Messages**：对话头圆形小头像（约 28–36pt）  
- **Slack / Discord**：顶栏或侧栏圆形头像 ≈ 24–32px  
- **系统设置入口**：SF Symbol `gearshape` / Lucide `settings` = **带齿齿轮 + 中心孔**

## 2. 目标形态

### 2.1 Wireframe（改后）

│                                 ↑   ·平静  ↑ │

改前对照：

```
│  ≡                    ☀?   阿盆   〔大脸 52〕 │
│                     射线图标        偏角色立绘   │
```

### 2.2 头像规格（推荐默认）

| 项 | 推荐 |
|---|---|
| 视觉直径 | **28px**（顶栏 44 高内留白舒适；可选 32 若嫌小） |
| 形状 | **正圆** `border-radius: 50%` + `overflow: hidden` |
| 描边 | `1px solid var(--line)` 或极淡 ink 8% |
| 光晕 `::before` | **顶栏尺寸关闭**（仅 lg / 空态保留可选） |
| Hover | 顶栏：**无位移**；可选 `opacity` / 轻微 `scale(1.04)` |
| Active / poke | 保留 poke 涟漪，但涟漪半径贴合 28px 圆 |
| 内容 | 仍用现有皮肤图 / SVG（`object-fit: cover` 裁进圆） |
| 可点 | 仍 poke（与 v2 一致） |

实现建议（变更最小）：

- `PokeFace` 增尺寸 **`xs`**（或改名 `avatar`）→ class `.face-xs`  
- 顶栏 `PresenceBadge` 改用 `size="xs"`  
- `.face-xs`：**28px**；覆盖/关闭 `::before`；弱化 hover 位移  
- `.face-sm` 可留给别处或废弃；**空态 / 设置·形象**继续 `lg`，不动

### 2.3 设置图标规格（推荐默认）

换成常见 **cog** 线框（24 viewBox，stroke ≈ 1.7，与 ≡ 一致）：

```
外圈：带 6～8 个矩形齿的齿轮轮廓
内圈：空心圆（孔）
```

伪 SVG 结构（实施时落真实 path）：

```
<!-- 经典 settings / gearshape -->
<path d="…齿轮外轮廓…" />
<circle cx="12" cy="12" r="3" />  <!-- 中心孔用 stroke 圆，不填充实心块 -->
```

| 项 | 推荐 |
|---|---|
| 隐喻 | **齿轮**，不要太阳/射线/调色盘 |
| 尺寸 | 与 `.chrome-icon-btn svg` 同为 **16×16** |
| 颜色 | `currentColor` → `--muted`；hover → `--ink` |
| 位置 | 仍在头像**左侧**（v2 已定，不改） |

会话 ≡ 图标本次**不改**（已是常见汉堡/列表形）。

### 2.4 Presence 文案

保留「阿盆 + 情绪点」在头像左侧、右对齐；字号维持。头像缩小后，右侧簇更紧凑：

```
[⚙ 32] [名/情绪] [◎ 28]
```

## 6. 成功标准

1. 顶栏头像视觉 ≤32px，正圆，无大光晕。  
2. 设置图标一眼可识别为「设置/齿轮」。  
3. 布局仍为：左 ≡ · 右 ⚙ · 文案 · 头像（最右）。  
4. 空态 / 形象页大脸无回归；相关单测不红。
