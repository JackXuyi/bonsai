## 2. 移除盆栽（范围）

### 2.1 删除清单（实施时对照）

| 区域 | 动作 |
|---|---|
| `BUILTIN_SKINS` / `skins.tsx` | 去掉 `id: "bonsai"` 与 `BonsaiFace` 注册 |
| `BonsaiFace.tsx` 及仅被其引用的成长形态线（若无他用） | 删除或确认无引用后删 |
| 设置·形象 `FaceSkinCard` | 不再展示盆栽卡 |
| 单测 / story 里 `skinId: "bonsai"` | 改 `fatfish` 或 `deepseek` |
| 文案「窗台上的那棵小树」等空态 | 改为与大肥鱼/可配置名一致 |
| 若用户本地已选 `bonsai` | 迁移：**读到 `bonsai` → 回落 `fatfish`**（一次，写回 store） |

### 2.2 保留

- 自定义皮肤上传（与盆栽无关）  
- `deepseek` 单图小鲸（缺槽 / 无表情态 fallback）  
- `fatfish` 默认表情皮（合入规则见 v3）

### 2.3 注册表（改后）

```
BUILTIN_SKINS:
  fatfish   ★ DEFAULT   image-set   大肥鱼表情
  deepseek              image       官方小鲸 logo（fallback）
  + custom…
# 无 bonsai
```

## 3. 可配置名称

### 3.1 推荐默认名：**大肥鱼**

| 候选 | 理由 | 结论 |
|---|---|---|
| **大肥鱼** | 与默认视觉、社区称呼、DSH 参考一致；两字以上好认 | **推荐默认** |
| 肥鱼 | 更短，略随意 | 可选用户自改 |
| 阿鱼 | 亲近，但弱化梗 | 不推荐作出厂默认 |
| 阿盆 | 旧盆栽人设，与形象移除冲突 | **退役为默认** |

出厂：`persona.name = "大肥鱼"`。用户可在设置改成任意称呼（见校验）。

### 3.2 权威源（一份事实）

| 层 | 职责 |
|---|---|
| **权威** | `persona.json` 的 `name`（经现有 `get_persona` / 更新 persona 的 command；若尚无「只改名」API 则最小加一个校验后的 set） |
| **消费** | ChatPet tooltip、空态标题、设置·形象预览名、（若做）消息行名、prompt 渲染里的自称/称呼注入（已有人格渲染器则走同一字段） |
| **禁止** | 前端再硬编码「阿盆」；禁止第二份 `displayName` store 与 persona 漂移 |

前端可对 `name` 做 zustand 缓存，但 **写入必须打回 Rust persona**，读以 snapshot / get_persona 为准（信任边界：校验在 Rust）。

### 3.3 设置 UI

```
设置 · 形象
  ┌─────────────────────────────────────┐
  │ 称呼  [ 大肥鱼          ]  （1–12 字）│
  │ 预览 ChatPet / 空态标题随称呼变       │
  │ 皮肤  ★大肥鱼  · 小鲸  · 自定义…     │
  └─────────────────────────────────────┘
```

- 位置：与皮肤同一「形象」分区（不必新开导航）。  
- 校验（Rust MUST）：非空；trim；长度 **1–12**（中文按字 / Unicode scalar）；拒绝控制字符；失败返回可区分错误，前端不假装成功。  
- 空态副文案：可用固定句（如「社区同人形象 · 非官方」）或短 desc，**主标题 = 当前称呼**。

### 3.4 顶栏

仍按 v2：**右侧只留 ⚙**，不因可配置名把名字加回顶栏。名字出现在 ChatPet 悬停与空态即可。

### 3.5 Wireframe（名称可见处）

```
空态：
        [大脸 fatfish]
         大肥鱼          ← 可配置
    社区同人 · 非官方

ChatPet hover：
    「大肥鱼 · 平静」   ← 名 + 情绪
```
