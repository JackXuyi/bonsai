## 0. 相对 v1 的转向

| v1 | v2（本版） |
|---|---|
| 主打：消息行 IM 挂头像 | **主打：聊天区角上浮动互动头像**（对标 DSH 桌宠感，素材仍用阿盆） |
| 顶栏保留「阿盆 · 情绪 + 小脸」 | **顶栏右侧只留 ⚙**；脸迁入聊天框角 |
| 未谈主题色 | **主题色换肤**为一等能力 |
| 消息行头像为 MUST | **降为可选 P1**（角上头像已提供 presence；窄托盘不宜双重头像） |

仍继承 v1：**不抄鲸鱼娘 IP**；人格权威仍是 `persona.json`「阿盆」；默认视觉回到盆栽语汇。

## 4. 主题色换肤

### 4.1 机制

- 权威：一组命名主题 → 覆盖 `:root`（或 `html[data-theme="…"]`）上的 **语义 CSS 变量**。  
- 现有变量已集中在 `base.css`（`--bg` / `--accent` / `--card` / `--line` …），换肤 = **换变量包**，业务组件继续吃变量，**禁止**主题色散落硬编码。  
- 持久化：`localStorage` 或既有 settings store（前端）；不进 Rust 密钥域。  
- 默认主题保持当前「苔绿盆栽」语汇（可微调，但不强制改成 DSH 深蓝玻璃）。

### 4.2 建议主题包（v2 最少 3–4 套）

| id | 氛围 | 用途 |
|---|---|---|
| `moss` | 苔绿 + 暖纸（现状演化） | **默认** |
| `ink` | 墨青 / 深底浅字 | 夜间少刺眼；非「为黑而黑」 |
| `clay` | 陶土褐 + 浅沙 | 盆器材质感 |
| `paper` | 素纸高对比、弱彩 | 专注阅读 |

每包至少覆盖：`--bg` `--bg-sunk` `--card` `--ink` `--muted` `--accent` `--accent-ink` `--accent-wash` `--line` `--shadow`（及 face 里依赖的 leaf/pot 若要联动）。

### 4.3 非目标（换肤）

- 不做任意色取色器（先预设包）。  
- 不做跟外部 DSH 主题文件互通。  
- 不做整页玻璃拟态大改造；主题包可带轻度 blur，但以可读性优先。

## 5. ChatPet（聊天框右上角互动头像）

| 项 | 规格 |
|---|---|
| 位置 | 聊天主列 **右上角**（`chat-stage` 内 `position: absolute`）；留出与顶栏/滚动条的边距 ≈ 8–12px |
| 尺寸 | **72–88px**（托盘窄时 56–64px） |
| 交互 | **poke**（现有涟漪）；悬停可显示「阿盆 · {情绪}」 |
| 状态 | 跟全局 `FaceState`；`chatting`/streaming → 强制 `thinking` |
| 层级 | 高于消息、低于 modal/drawer；`z-index` 固定；**不拦截**消息区左侧与 Composer 点击（仅头像自身 hit 区） |
| 空态 | 推荐：**有消息才显示角上头像**；空态只用居中大脸（避免双脸） |
| 关闭 | 设置「角上头像」可关；关掉后顶栏仍不恢复 PresenceBadge |

与 Composer：头像在右上，Composer 在底，默认不重叠；若小窗高度极矮，头像可自动缩到 48px 或上移避让。

## 6. 顶栏收口（只留设置）

| 元素 | 处置 |
|---|---|
| ≡ 会话 | **保留**（左） |
| ⚙ 设置 | **保留**（右，唯一右侧入口） |
| PresenceBadge（名 / 情绪点 / xs 脸） | **移除出顶栏** |
| 模型 / 任务 / token 等 | **不进顶栏**（模型仍在 Composer `ModelChip`；任务能力在工具/对话，不在 chrome） |

验收：`ChatChrome` 右侧 DOM 仅设置 `Link`；`ChatChrome.test` 更新断言。

## 7. 表情与回合（相对 v1 收窄）

角上头像已承担「运行中思考 / 闲时心情」：

- **MUST**：streaming → `thinking`；结束回 face 运行时态或简单规则（成功 `calm`/`proud`，失败 `displeased`）。  
- **P1**：v1 的每条消息锁脸 + 持久化 —— 仅当角上头像不足以表达「这一轮演了什么」再做。  
- **不做**：每轮默认 LLM 表情分类；鲸鱼娘桌宠 iframe。

## 10. 风险

| 风险 | 缓解 |
|---|---|
| 角上头像挡消息/操作条 | 固定右上安全区；消息列表右 padding；hit 区仅圆形 |
| 主题包漏变量导致对比度崩 | 每包 checklist + 一两处快照/手工扫设置页 |
| 用户找不到「阿盆」状态 | tooltip + 设置·形象预览 |
| 与 DSH 视觉雷同 | 不用深蓝玻璃默认、不用二创立绘；衬底用盆栽 |
